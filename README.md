# One must imagine the deltahead happy

Heya, this is the third film in the *One must imagine the stonehead happy* series, made entirely in Stone Story RPG's
Mind Stone (Stonescript). A Pusher walks off his track and climbs to the top of the world. It plays in the game at the
Deadwood waterfall and runs about 13 minutes, with sound.

## Install

You need the PC version of the game.

1. Download this repo as a ZIP and unzip it
2. Copy the "stonescript/Deltahead" folder into the game's Stonescript folder
   ("%USERPROFILE%\AppData\LocalLow\Martian Rex, Inc_\Stone Story\<your id>\Stonescript"), so you end up with
   "...\Stonescript\Deltahead\Main.txt"

## Watch

1. Add this line to your Mind Stone:

   ```
   import Deltahead/Main
   ```

2. Go to the Deadwood waterfall
3. Click the rainbow ∆ that says "Continue to Animation"
4. Turn "Screen Flashes" and "Camera Shake" on or off, then press "Start Animation"

To stop, just leave the waterfall.

## Wear the Deltahead

```
import Deltahead/Wear
```

Puts a ∆ on your head (with Big Head on too). It's white until you've watched the film to the end, then rainbow.

NOTE: put each import on its own line with nothing after it (not even a comment), or the game won't read it.
